## 1. Project Description

**AI in Transportation** is an interactive, Python-generated web project designed for the Python Fundamentals Lab. Modern urban transportation systems rely heavily on Artificial Intelligence to mitigate traffic congestion, enhance passenger safety, dynamically optimize routes, and power autonomous vehicles.

This project uses **pure standard Python (no external libraries)** to:
1. Store and structure route data using lists of dictionaries.
2. Calculate estimated travel times using arithmetic within a custom Python function (`travel_time`).
3. Identify the fastest travel option using Python's built-in `min()` with a custom `key` argument.
4. Dynamically generate a modern, responsive HTML5 webpage (`index.html`) using Python `for` loops, conditional logic, and formatted f-strings.
5. Write the resulting webpage directly to the filesystem using Python's built-in `open()` context manager.

## 2. Python Fundamentals Demonstrated

This project adheres strictly to Python fundamentals and the lab rubric:

| Python Concept | Where & How It Is Used in `main.py` |
| :--- | :--- |
| **Functions (`def`)** | `def travel_time(distance, speed):` defines a reusable function calculating travel time in minutes. |
| **Arithmetic Operators** | Division (`/`) and multiplication (`*`) calculate travel time: `(distance / speed) * 60`. |
| **For Loops (`for ... in`)** | Iterates over routes to compute travel times and dynamically build HTML table rows; iterates over benefits to generate benefit cards. |
| **String Formatting / f-strings** | Formats numerical values to two decimal places (`{time_minutes:.2f} min`) and embeds variables into the HTML template with escaped CSS braces (`{{ ... }}`). |
| **Lists & Dictionaries** | `routes` stores 5 structured route records; `benefits` stores transit benefits with icons and descriptions. |
| **Conditional Logic (`if/else`)** | Detects the fastest route (`if route == fastest_route:`) to apply distinct CSS classes and attach the `⚡ FASTEST ROUTE` badge. |
| **`min()` with `key` function** | Efficiently computes the route with the minimum travel time: `min(routes, key=lambda route: travel_time(route["distance"], route["speed"]))`. |
| **File Handling (`open`)** | Writes the generated HTML to `index.html` using `with open("index.html", "w", encoding="utf-8") as f:`. |
| **No External Libraries** | Uses only Python's standard library (100% zero-dependency). |

## 8. Viva / Demonstration Quick Guide (For Oral Exam)

When presenting this project to your instructor or examiner, be ready to explain:

1. **Why `(distance / speed) * 60`?**
   * `distance / speed` gives travel time in hours.
   * Multiplying by `60` converts hours into minutes.

2. **How does `min(routes, key=...)` work?**
   * Instead of finding the minimum dictionary directly (which would fail), the `key` parameter tells Python to pass each route dictionary to `travel_time(route["distance"], route["speed"])` and compare those numerical results.

3. **Why are CSS braces doubled in `main.py` (`{{` and `}}`)?**
   * In a Python f-string, single curly braces `{...}` denote variable interpolation. To output a literal `{` or `}` in the generated CSS, Python requires them to be escaped as `{{` and `}}`.

4. **Why use `with open(...)`?**
   * The `with` statement creates a context manager that automatically closes the file when writing is complete, even if an unexpected error occurs.
